# Techies Lab Sales Page

A static, mobile-friendly sales page built with HTML, CSS and JavaScript.

## Files
- `index.html` - website structure
- `style.css` - design and responsive layout
- `script.js` - product modal, search, filters and mobile menu

## Customise before publishing
1. Replace `TL` with your final logo if desired.
2. Update product names, prices and descriptions in `index.html`.
3. Update the product data in `script.js`.
4. Replace the WhatsApp number `2349071766222` if needed.
5. Review all software names, versions, licensing, pricing and claims before publishing.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all three website files.
3. Open **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder.
6. Save and wait for GitHub to publish the site.

For a project repository, the usual URL format is:
`https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/`

If the repository is named `YOUR-USERNAME.github.io`, it can be published at:
`https://YOUR-USERNAME.github.io/`
